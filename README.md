# 学生论文写作助手 · 产品作品集

AI 产品经理作品集 —— 一款面向高校学生与研究者的 AI 论文写作辅助 SaaS 的 0→1 产品实践。

## 在线查看

https://aaa-geeker.github.io/student-paper-portfolio/

## 内容

- **项目概览** —— 产品定位与三大核心痛点切入
- **产品实态** —— 真实产品界面截图（线上环境）
- **功能设计** —— 降重降 AIGC / 投稿前审查 / 论文修改 + 5 项辅助功能
- **商业化设计** —— 付费体系与转化链路（不涉及具体定价）
- **产品决策** —— 三个关键判断的思考过程
- **边界与反思** —— 已落地 vs 未落地能力，以及复盘

## 技术实现

- 后端：FastAPI + PostgreSQL
- 前端：React + TypeScript
- AI：DeepSeek API
- 部署：Docker Compose + Nginx（腾讯云）
